## 2. Креативная идея: «Тихая вода»

Лебедь на спокойной воде. Спокойствие — это то, чего нет у человека, чей питомец болен. Сайт передаёт его как состояние: много воздуха, медленные плавные движения, ощущение дорогой частной медицины.

Три фирменных приёма, которых нет у конкурентов (именно они «впечатляют»):

1. **Сайт живёт по московскому времени.** Днём — светлая «молочная» тема. С 21:00 до 9:00 (дежурная смена) hero переключается на **ночной режим**: глубокий сине-зелёный фон, луна, звёзды, «Дежурная смена принимает прямо сейчас», кнопка «Позвонить» уже на первом месте. Есть переключатель. Это воплощает главную мысль сайта буквально и запоминается.
2. **Лебедь одной линией.** Собственный SVG-лебедь (stroke 1.25 px) рисуется при загрузке и становится сквозным мотивом: разделитель секций, фавикон, OG-картинка, прогресс прокрутки, курсор загрузки. Под ним тонкие линии воды с лёгкой рябью.
3. **Сцена «Лапароскопия»** на pin + scrub: силуэт собаки, большой разрез стирается и превращается в точки-проколы, вокруг пульсирует кольцо газового наркоза, силуэт уходит в капсулу кислородной камеры. Это не декоративная анимация, а объяснение сложной услуги за 15 секунд скролла.

Дополнительные «вау»-детали: живой поиск по реальному прайсу, схема Москвы с прорисовкой связей к клиникам, лента врачей с перетаскиванием и перестройкой по фильтрам, текст-маски в заголовках, плавный Lenis-скролл, магнитные кнопки, count-up рейтинга.

## 3. Принципы (чтобы не разошлись)

- Ничего не выдумывать. Неизвестное → видимая заглушка `[…]` (пунктирная рамка). Известное → строго из `docs/02-CONTENT.md`.
- Цитаты только из банка отзывов, дословно, подпись «Отзыв на Яндекс Картах». Перед публикацией сверить с оригиналом (пометка в README).
- «Вы/Вам/Ваш» с заглавной. Живой русский, без штампов.
- Только `transform`/`opacity`/точечно `filter`. `prefers-reduced-motion` уважается везде.
- Mobile-first: открываем сначала на 390 px. Нижняя панель «Позвонить · Маршрут · Записаться».
- Не показываем: негатив Олимпийской деревни, медицинские советы сверх безопасного минимума (всегда «Это не диагноз»), «2000 питомцев в месяц» (в промпте запрещено как неподтверждённое; в брифе — наоборот, берём из текста нынешнего сайта; **решение: не используем**, см. DECISIONS), «более 10/15 лет» (пишем «с 2006 года»).
- Зоомагазин — только в футере.

## 4. Ограничения среды (влияют на решения)

- Unsplash/Pexels и vetlebedi.ru из песочницы недоступны → **стоковых фото и фото врачей нет**. Вместо этого собственная иллюстративная система: линейные SVG, мягкие градиенты воды, зерно, монограммы врачей. Это сознательный стиль, а не заглушка; фото клиники подключаются одной заменой файла (`/public/img`, слоты описаны в README).
- Шрифты ставим через `@fontsource-variable` (npm), без запросов к Google на сборке и в браузере. Кириллица есть.
- Деплой: статический `out/` → Cloudflare Pages / GitHub Pages. В песочнице деплоить нельзя, готовим конфиг и инструкцию.

## 6. Главная: секции (порядок из промпта, уточнения мои)

1. **Шапка**: логотип-текст «Лебеди» + лебедь; индикатор «● Открыто сейчас · 02:14»; меню; телефон; «Записаться»; сжатие при скролле + blur.
2. **Hero «Что случилось?»**: заголовок «Ветеринарная клиника, где Вам всё объясняют»; подзаголовок «С 2006 года · Круглосуточно · Три клиники»; виджет-плитки; рейтинг-бейдж 5.0 · 1 758 оценок; день/ночь по времени.
3. **Полоса доверия**: С 2006 года · Круглосуточно · 26+ врачей · Реанимация и стационар.
4. **Клиники**: 3 карточки + SVG-схема Москвы, статусы «открыто», маршруты.
5. **Направления**: 10 карточек с линейными иконками.
6. **Сцена «Лапароскопия»** (тёмная, pin+scrub).
7. **Стационар и реанимация**: 3 колонки + «Как мы держим Вас в курсе» + «Как проходит выписка» (закрывает жалобы из отзывов).
8. **Врачи**: лента с drag, фильтры, трое-пятеро из отзывов первыми.
9. **Экзотика**: светлый блок со списком из прайса (11 групп — реальные данные).
10. **Зоотакси**: линейная иллюстрация, кнопка вызова.
11. **Прайс-превью**: 6 ключевых позиций + «Весь прайс» (реальные цены).
12. **Отзывы**: 5.0, 4 400 оценок суммарно по трём картам (честно: считаем по карточкам), 6–8 цитат, ссылка на Карты.
13. **FAQ** + **финальный CTA** (телефон огромным шрифтом).
14. **Футер**: адреса, меню, «Зоомагазин в клинике», контроль качества control@, метка концепта.
