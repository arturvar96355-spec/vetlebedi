# Дизайн-система · «Тихая вода»

## 1. Настроение

Спокойный премиум, «тихая уверенность». Эталон ощущения: хорошая частная клиника для людей, а не зоомагазин. Много воздуха, крупная высококонтрастная антиква, тонкая линейная графика, медленные движения (800–1200 мс, ease-out).

## 2. Палитра

Основа взята из промпта (молоко / чернила / озеро / тростник / песок / тревога). Фирменные цвета нынешнего сайта (бирюзовый #0CB8B6, оранжевый #F36438) сознательно **уходят в тень**: бирюза живёт как светлый акцент «вода», оранжевый не используется (красный `alert` только для «Срочно»), чтобы визуально отстроиться от шаблонной темы Medicare.

| Токен | Значение | Роль |
|---|---|---|
| `milk` | `#F6F2EA` | фон |
| `milk-2` | `#FBF8F2` | приподнятый фон, поля |
| `ink` | `#10302E` | текст |
| `ink-soft` | `#3C5A57` | второй текст (контраст на milk ≥ 7:1) |
| `lake` | `#1F5A55` | кнопки, акцент |
| `lake-deep` | `#163F3C` | hover кнопок |
| `reed` | `#8FB3A5` | линии, иконки |
| `reed-pale` | `#CFE0D7` | тонкие заливки |
| `sand` | `#E6DCCB` | карточки |
| `alert` | `#C2412D` | только «Срочно» и «Позвонить» на мобильной панели |
| `night` | `#0E2624` | тёмные секции |
| `night-2` | `#143633` | карточки на тёмном |
| `moon` | `#EDE7DC` | текст на тёмном |

Градиенты «воды»: `radial-gradient` из reed-pale/milk для дня, из `#1B4743`/night для ночи. Зерно — SVG feTurbulence 3–4 % поверх фона (один слой на странице).

## 3. Типографика

- Заголовки: **Cormorant** (variable, кириллица), вес 500–600, трекинг −0.02em, `font-feature-settings: "ss01"` не нужен. Крупные кегли: Hero `clamp(44px, 7.2vw, 112px)`, H2 `clamp(34px, 4.6vw, 68px)`, H3 `clamp(24px, 2.4vw, 34px)`.
- Текст: **Onest** (variable), 17 px (≥16), line-height 1.6, `text-wrap: pretty`; заголовки `text-wrap: balance`.
- Цифры: `font-variant-numeric: tabular-nums` для рейтинга, цен, времени.
- Подписи-оверлайны: Onest 12.5 px, капс, трекинг 0.14em.
- Типограф (`typograph()`): неразрывные пробелы после предлогов/союзов 1–2 буквы и перед `₽`, «ёлочки», тире « — ».

## 4. Сетка и форма

12 колонок, max-width 1280, поля 20 px (моб.) / 48 px (десктоп). Радиусы: карточки 24–28 px, поля 16 px, кнопки — капсулы. Тени: мягкие, зелёно-серые (`0 24px 60px -24px rgb(16 48 46 / .28)`), без чёрных. Межсекционный ритм: 112–160 px на десктопе, 72–96 px на мобильном.

## 5. Графика

### Лебедь (фирменный знак)
- Один SVG-path, stroke 1.25 px (в больших размерах масштабируется `vector-effect: non-scaling-stroke`), `stroke-linecap: round`.
- Анимация: `pathLength=1`, `stroke-dasharray:1`, `stroke-dashoffset` 1 → 0 за 1.6 с, затем «дыхание» scale 1 → 1.01 за 6 с.
- Варианты: большой (hero), малый (логотип), разделитель (лебедь на волне), фавикон, OG.
- Это стилизованный оригинал, не копия логотипа клиники. Текстовый логотип «Лебеди» — Cormorant 600.

### Вода
Тонкие горизонтальные синусоидальные линии под лебедем (3–5 штук, разная амплитуда), медленно «текут» (translateX loop, 14–22 с). На ночь — лунная дорожка.

### Иллюстрации вместо фото
Нет доступа к стокам и к фото клиники → набор своих линейных иллюстраций в одном стиле (stroke 1.25–1.5 px, закругления, один акцентный заполненный элемент цвета reed-pale):
силуэт собаки (сцена хирургии), кошка, птица, черепаха/рептилия, грызун, машина зоотакси, капсула кислородной камеры, стетоскоп, монитор ЭКГ, капельница, лабораторная колба.
Фото клиник и врачей подключаются позже: слоты с `[фото — от клиента]`.

### Монограммы врачей
Круг/скруглённый квадрат с инициалами, фон — детерминированный из палитры (reed-pale / sand / lake / night), тонкая линия лебедя на фоне, подпись `[фото — от клиента]` только мелко.

## 6. Тема день / ночь

- `data-theme="day" | "night"` на `<html>`. По умолчанию определяется **по московскому времени** (21:00–9:00 → night для hero-блока и шапки, остальная страница остаётся светлой, тёмная только сцена хирургии и футер).
- Переключатель в шапке (иконка солнце/луна), состояние в `localStorage` (try/catch), «авто» по умолчанию.
- Ночной hero: фон `night`, звёзды (≤40 точек, CSS-мерцание на opacity), луна с мягким ореолом, лунная дорожка на воде, заголовок «Дежурная смена принимает прямо сейчас», кнопка «Позвонить» крупнее.
- Все цвета через CSS-переменные; контраст проверяется в обеих темах (≥ AA).

## 7. Движение

| Приём | Параметры |
|---|---|
| Reveal секций | opacity 0→1, y 32→0, blur 6→0, 0.9 с, `ease [0.22,1,0.36,1]`, once, порог 0.18 |
| Заголовки | маска по словам, stagger 50 мс, 0.9 с |
| Count-up | 1.4 с, ease-out |
| Hover карточек | y −4, тень, рамка reed → lake, 240 мс |
| Магнитные кнопки | ≤ 8 px, только `pointer: fine` |
| Скролл | Lenis (lerp 0.1), синхронизация с ScrollTrigger |
| Сцена хирургии | GSAP pin + scrub, 4 шага |
| Прогресс | тонкая линия-вода сверху, заполняется по скроллу |
| Reduced motion | отключаем pin/scrub/параллакс/автодвижение, оставляем мгновенную смену состояний |

На < 768 px: без pin, без параллакса, меньше слоёв, сцена хирургии — 4 карточки с появлением.

## 8. Компоненты

`Button` (primary/lake, ghost, alert, на тёмном; магнитный), `Pill/Badge` (открыто/закрыто, 24/7), `Card` (sand/milk/night), `Placeholder` (пунктирная рамка для `[…]`), `Field/Select/Chip`, `Accordion` (Motion layout), `Marquee`, `Reveal`, `SplitHeading`, `Counter`, `SwanDraw`, `WaterLines`, `Monogram`, `StatusDot`, `SectionDivider` (лебедь на волне), `BottomBar` (моб.), `Header`.

## 9. Доступность

Один `h1` на страницу; `nav`/`main`/`footer`; `alt` у всего содержательного; видимый `:focus-visible` (2 px lake + offset 3); тап-зоны ≥ 44 px; виджеты управляются клавиатурой (стрелки, Enter, Esc); viewport **без** запрета зума; `lang="ru"`; skip-link.

## 10. Мобильная версия

Проектируем сначала её. Hero: заголовок → подзаголовок → плитки «Что случилось?» (2×2) → бейдж рейтинга. Нижняя панель 56 px: «Позвонить» (alert), «Маршрут», «Записаться»; контент получает `padding-bottom` под неё.
